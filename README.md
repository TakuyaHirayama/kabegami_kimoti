# 今日の気分で壁紙が変わるAIお天気×感情ダイアリー

## アプリ概要
このアプリは、ユーザーが入力した「今日の気分」と、現在の天気情報をもとに、  
AIが最適な壁紙と一言コメントを提案するWebアプリです。

気分と天気の履歴はSupabaseに保存され、後から振り返ることができます。

---

## 主な機能
- 気分の選択（元気／疲れた／集中したい／落ち込み気味）
- OpenWeatherMap API を用いた現在の天気取得
- AI風コメントの自動生成
- Supabase による履歴保存・表示

---

## 使用技術

- Supabase
- OpenWeatherMap API
